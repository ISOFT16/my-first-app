# Fox Company — фирменный стиль

Та же геометрическая лиса, что в Fox Browser (`lib/widgets/fox_logo.dart`), палитра «песок и кофе» (`lib/theme.dart`) и шрифт Google Sans. Текст в SVG переведён в контуры, поэтому логотип выглядит одинаково везде, даже без установленного шрифта.

## Файлы
| Файл | Где использовать |
|---|---|
| `png/youtube-avatar.png` (800×800) | аватар YouTube и других соцсетей (YouTube обрезает по кругу — всё важное в центре) |
| `png/youtube-banner.png` (2560×1440) | шапка канала YouTube (надпись в безопасной зоне 1546×423 — видна на телефоне, ПК и ТВ) |
| `png/watermark-150.png`, `png/watermark-300.png` | водяной знак в видео (YouTube Studio → Настройка → Брендинг) |
| `png/logo-horizontal-light.png` / `-dark.png` | логотип со словами для светлого / тёмного фона (сайт, превью, документы) |
| `png/logo-vertical-light.png` / `-dark.png` | вертикальный вариант (заставка в видео, обложки) |
| `png/icon-light.png`, `icon-dark.png`, `icon-circle.png` (1024×1024) | значки приложений, иконки, стикеры |
| `svg/*.svg` | исходники в векторе — масштабируются без потерь (печать, большие баннеры) |

